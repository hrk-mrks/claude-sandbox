# スマホ寿司打

スマホで遊べる寿司打風タイピングゲーム。`index.html` 1ファイルのみ（ビルド不要）。

## 遊び方

1. `index.html` をブラウザで開く（GitHub Pages などに置けばスマホからアクセス可）
2. 「スタート」を押すとソフトキーボードが出る。英字キーボードに切り替える
3. 表示された単語をローマ字で 60 秒間ひたすら打つ

## 仕様

- ローマ字のゆれに対応（shi/si、chi/ti、tsu/tu、ja/zya、っ=子音重ね or xtu、ん=n/nn/xn など）
- 単語は `index.html` 内の `WORDS` 配列（`[表示, かな]`）に追加するだけで増やせる
- 結果画面で皿数・正確率・キー/秒を表示

## ローカルで試す

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```
